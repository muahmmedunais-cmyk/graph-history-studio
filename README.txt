GRAPH.HISTORY STUDIO — WEBSITE PACKAGE

Files:
- index.html: responsive landing page
- editor.html: Fabric.js design editor
- graph-history-logo.png: supplied Graph.History logo

Install:
1. Upload all three files to the same GitHub Pages folder/root.
2. Keep the filenames exactly as shown.
3. Commit and push. Open index.html through your GitHub Pages URL.

Included editor features:
- Existing canvas editing, image upload, editable text, shapes, layers, undo/redo,
  local autosave, project import/export, PNG/JPG/SVG export.
- 100 editable template presets in 10 categories. Templates are composed from
  editable Fabric.js text and shape objects, not flattened poster images.
- 50 English font-family choices. Google Fonts are loaded on demand; internet
  access is required for those hosted font files. Local custom font upload remains.
- Elements library with symbol/icon glyphs, graphic marks, stickers, frames and
  editable mockup scene starters. Upload transparent PNG/SVG/image files to add
  your own real asset artwork.

Limitations stated honestly:
- The Elements panel is a starter library, not a large commercial stock PNG library.
- Mockup scenes are editable compositions, not Photoshop smart-object perspective
  warping. For photographic mockups, upload your own mockup image.
- External Fabric.js and Google Fonts require internet access.
